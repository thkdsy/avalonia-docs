本页面用于排查登录 [Avalonia Plus、Pro、Enterprise](https://avaloniaui.net/pricing) 或 [XPF](/xpf) 订阅时遇到的常见问题。

## 凭据错误

你的 Avalonia 凭据用于登录 [门户](https://portal.avaloniaui.net/)。这些凭据与你用于访问 Avalonia 开发工具的凭据相同，例如 [Avalonia for Visual Studio 扩展](/tools/visual-studio-extension)、[开发工具](/tools/developer-tools/installation) 或 [Parcel](/tools/parcel/setup)。

与你账户关联的电子邮件通常是你所在组织提供的工作邮箱。

如果你忘记了密码，请尝试 [重置密码](https://portal.avaloniaui.net/forgot-password)。

## 从未收到邀请邮件

请检查你的垃圾邮件文件夹，以防你的邮件客户端将该邮件过滤到那里。

考虑将 `@avaloniaui.net` 添加到你的安全发件人列表，以免错过我们发送的邮件。

## 错误消息："未找到有效的订阅席位。"

你的组织拥有订阅，但尚未为你分配席位。请联系你组织的管理员申请分配席位。相关说明请参阅 [分配席位](/tools/assigning-seats) 页面。

## 我需要更多帮助

更多信息请访问 [门户](https://portal.avaloniaui.net/)。
