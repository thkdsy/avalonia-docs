当你发布 Avalonia Browser 项目时，.NET SDK 会将应用编译为 WebAssembly（Wasm）——一种可以直接在浏览器中运行的二进制格式。输出结果是一个静态站点，其中包含 `index.html` 文件、编译后的 `.wasm` 模块、.NET 运行时文件以及各种静态资源。这里没有任何服务端代码，所有内容都在浏览器的 Wasm 运行时中于客户端执行。

由于输出完全由静态文件组成，你可以把它部署到任意 Web 服务器或静态托管服务上，例如 Azure Static Web Apps、GitHub Pages、AWS S3、Nginx，或者任何 CDN。服务器端不需要安装 .NET 运行时。

## 发布

在 Browser 项目目录中运行：

```bash
dotnet publish -c Release
```

SDK 会在 `bin/Release/<tfm>/publish/wwwroot` 下生成应用包，其中 `<tfm>` 对应你的目标框架（例如 `net9.0-browser` 或 `net8.0-browser`）。发布后的输出结构如下：

这个 `wwwroot` 目录已经包含了运行应用所需的全部内容。将其内容上传到你的托管服务即可。

:::note
在较旧版本的 .NET SDK 中，应用包位于 `bin/Release/<tfm>/browser-wasm/AppBundle`。
:::

:::caution
在使用 `dotnet publish` 时，`-o` 或 `--output` 参数并不会把应用包放进你指定的输出目录。你仍然需要从 `bin` 目录中获取它。详情请参见 [dotnet/runtime#94319](https://github.com/dotnet/runtime/issues/94319)。
:::

## 本地测试

在部署之前，你可以使用 [dotnet-serve](https://github.com/natemcmaster/dotnet-serve) 在本地提供已发布输出的静态服务：

```bash
dotnet tool install --global dotnet-serve

dotnet serve -d:bin/Release/net9.0-browser/publish/wwwroot
```

然后打开终端输出中显示的 URL（例如 `http://localhost:49875`），以验证应用是否按预期工作。

## 优化包体积

WebAssembly 应用会包含 .NET 运行时以及所有被引用的程序集，因此首次下载体积可能会比较大。你可以考虑以下方式来减小包体积：

- **裁剪（Trimming）**：在 release 构建中默认启用。链接器会从程序集中移除未使用代码。请确保你的代码兼容裁剪，以避免运行时错误。
- **压缩**：大多数托管服务会自动使用 Brotli 或 gzip 压缩文件。如果你的服务不会自动压缩，请手动配置。Brotli 通常可以将 `.wasm` 文件体积缩小 60%-70%。
- **AOT 编译**：在项目文件中添加 `<RunAOTCompilation>true</RunAOTCompilation>` 后，可以提前把 IL 编译为 Wasm，从而提升运行时性能，但代价是下载体积更大、构建时间更长。

## 自定义加载界面

在 .NET 运行时和应用文件下载期间，浏览器会显示一个启动画面。默认的 Avalonia 模板会显示带有 Avalonia 标志的 “Powered by Avalonia” 文案。它定义在 Browser 项目的 `wwwroot` 文件夹中的 `index.html` 文件里：

```html
<div id="out">
    <div class="avalonia-splash">
        <h2>
            Powered by
            <a href="https://www.avaloniaui.net/" target="_blank">
                <!-- Avalonia SVG logo -->
            </a>
        </h2>
    </div>
</div>
```

如果你想替换成自己的品牌内容或加载指示器，可以编辑 `<div id="out">` 元素内部的标记。Avalonia 完成初始化并接管页面之前，这里的内容都会一直显示。样式则可以在配套的 `app.css` 文件中调整。

## 托管注意事项

由于输出是一个静态站点，你的 Web 服务器必须把 `.wasm` 文件以 `application/wasm` 内容类型提供出来。大多数现代服务器默认已经处理好了这一点，但如果你的应用无法加载，这通常是最先需要检查的地方。
