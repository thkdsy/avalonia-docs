Avalonia Linux 程序在大多数 Linux 发行版中都可以通过双击可执行文件，或在终端中直接启动来运行。不过，为了提供更好的用户体验，仍然建议将程序安装到系统中，这样用户就可以通过 GNOME、KDE 等桌面环境中的桌面快捷方式启动它，或者在命令行中通过加入 PATH 的方式直接运行。

Debian、Ubuntu 及其相关发行版通常会把应用打包成 `.deb` 文件，并可通过 `sudo apt install ./your_package.deb` 进行安装。

:::tip[Use Parcel for easier packaging]
[Parcel](/tools/parcel/packaging-for-linux) 可以自动为 Avalonia 应用完成 Linux 打包。它能够生成 `.deb`、`.rpm` 和 `.zip` 包，并自动处理桌面集成。你可以查看 [Parcel 配置指南](/tools/parcel/setup) 开始使用。
:::

## 手动打包

本页其余部分将介绍如何使用 `dpkg-deb` 手动创建 `.deb` 包。

在本教程中，我们会使用 `dpkg-deb` 工具来生成 `.deb` 包。

### 1）在暂存目录中整理程序文件

各目录含义如下：

* `DEBIAN`：存放 `control` 文件。
* `/usr/bin/`：存放启动脚本（推荐用于从命令行启动程序）。
* `/usr/lib/myprogram/`：存放 `dotnet publish` 生成的所有文件。
* `/usr/share/applications/`：存放桌面快捷方式文件。
* `/usr/share/pixmaps/` 与 `/usr/share/icons/hicolor/**`：存放应用图标。

:::info

`/usr/share/icons/hicolor/**` 是可选的，因为即使没有这些图像，你的应用图标通常也依然会显示在桌面环境中。不过，为了获得更好的多分辨率显示效果，仍然建议提供它们。

:::

### 2）编写 `control` 文件

`control` 文件应放在 `DEBIAN` 文件夹中。

这个文件用于描述程序的基本信息，例如名称、版本、分类、依赖项、维护者、处理器架构和许可证等。关于文件中所有可能字段的更详细说明，可参阅 [Debian 文档](https://www.debian.org/doc/debian-policy/ch-controlfields.html)。

:::tip[Author's comment]

不必太担心把所有可能的字段都填满，其中大多数都不是必需的。本教程的目标，是制作一个“足够好用”的 Debian 包。

:::

.NET 依赖项可以通过运行 `apt show dotnet-runtime-deps-8.0` 来查看（其他 .NET 版本的后缀会不同）；它们会出现在以 *Depends: ...* 开头的那一行中。你也可以在 [.NET Core 仓库](https://github.com/dotnet/core/blob/main/release-notes/8.0/linux-packages.md) 中查看。

Avalonia 所需依赖包括：`libx11-6, libice6, libsm6, libfontconfig1`。

总体来说，你需要包含所有 .NET 和 Avalonia 依赖，以及你的应用本身额外需要的其他依赖。

下面是一个简单的 `control` 文件示例。

```yaml
Package: myprogram
Version: 3.1.0
Section: devel
Priority: optional
Architecture: amd64
Installed-Size: 68279
Depends: libx11-6, libice6, libsm6, libfontconfig1, ca-certificates, tzdata, libc6, libgcc1 | libgcc-s1, libgssapi-krb5-2, libstdc++6, zlib1g, libssl1.0.0 | libssl1.0.2 | libssl1.1 | libssl3, libicu | libicu74 | libicu72 | libicu71 | libicu70 | libicu69 | libicu68 | libicu67 | libicu66 | libicu65 | libicu63 | libicu60 | libicu57 | libicu55 | libicu52
Maintainer: Ken Lee <kenlee@outlook.com>
Homepage: https://github.com/kenlee/myprogram
Description: This is MyProgram, great for doing X.
Copyright: 2022-2024 Ken Lee <kenlee@outlook.com>
```

### 3）编写启动脚本

推荐执行这一步，原因有两个：第一，可以降低桌面快捷方式配置的复杂度；第二，可以让你的应用直接从终端运行。

启动脚本的文件名最好命名为 `myprogram`（不带 `.sh` 扩展名），这样用户在终端中输入 “myprogram” 时，就可以直接启动你的程序。

**myprogram_executable** 文件通常会和它的 .NET 项目同名。例如，如果你的 Avalonia `.csproj` 项目名为 *MyProgram.Desktop*，那么 `dotnet publish` 生成的主可执行文件通常就叫 `MyProgram.Desktop`。

启动脚本示例：

```sh
#!/bin/bash
# use exec to not have the wrapper script staying as a separate process
# "$@" to pass command line arguments to the app
exec /usr/lib/myprogram/myprogram_executable "$@"
```

### 4）编写桌面快捷方式文件

桌面快捷方式文件遵循 [freedesktop 规范](https://specifications.freedesktop.org/desktop-entry-spec/desktop-entry-spec-latest.html#recognized-keys)。Arch Linux Wiki 也提供了[很好的相关资料](https://wiki.archlinux.org/title/Desktop_entries)。

下面是一个桌面快捷方式文件示例。

```conf
[Desktop Entry]
Name=MyProgram
Comment=MyProgram, great for doing X
Icon=myprogram
Exec=myprogram
StartupWMClass=myprogram
Terminal=false
Type=Application
Categories=Development
GenericName=MyProgram
Keywords=keyword1; keyword2; keyword3
```

:::tip

如果你的应用需要打开文件，请在 Exec 行末尾的 `myprogram` 后面追加 **%F**；如果它需要打开 URL，则追加 **%U**。

:::

### 6）编译 `.deb` 包

```sh
# 对于 x64 架构，推荐使用 amd64 后缀。
dpkg-deb --root-owner-group --build ./staging_folder/ "./myprogram_${versionName}_amd64.deb"
```

## 完整流程的 Linux Shell 脚本示例

```bash
#!/bin/bash

# 清理
rm -rf ./out/
rm -rf ./staging_folder/

# .NET 发布
# 建议使用 self-contained，这样最终用户就不需要额外安装 .NET
dotnet publish "./src/MyProgram.Desktop/MyProgram.Desktop.csproj" \
  --verbosity quiet \
  --nologo \
  --configuration Release \
  --self-contained true \
  --runtime linux-x64 \
  --output "./out/linux-x64"

# 暂存目录
mkdir staging_folder

# Debian control 文件
mkdir ./staging_folder/DEBIAN
cp ./src/MyProgram.Desktop.Debian/control ./staging_folder/DEBIAN

# 启动脚本
mkdir ./staging_folder/usr
mkdir ./staging_folder/usr/bin
cp ./src/MyProgram.Desktop.Debian/myprogram.sh ./staging_folder/usr/bin/myprogram
chmod +x ./staging_folder/usr/bin/myprogram # 为启动脚本设置可执行权限

# 其他文件
mkdir ./staging_folder/usr/lib
mkdir ./staging_folder/usr/lib/myprogram
cp -f -a ./out/linux-x64/. ./staging_folder/usr/lib/myprogram/ # 复制 publish 目录中的全部文件
chmod -R a+rX ./staging_folder/usr/lib/myprogram/ # 为所有文件设置读取权限
chmod +x ./staging_folder/usr/lib/myprogram/myprogram_executable # 为主可执行文件设置可执行权限

# 桌面快捷方式
mkdir ./staging_folder/usr/share
mkdir ./staging_folder/usr/share/applications
cp ./src/MyProgram.Desktop.Debian/MyProgram.desktop ./staging_folder/usr/share/applications/MyProgram.desktop

# 桌面图标
# 这里使用一张 1024px x 1024px 的 PNG，类似 VS Code 的图标做法
mkdir ./staging_folder/usr/share/pixmaps
cp ./src/MyProgram.Desktop.Debian/myprogram_icon_1024px.png ./staging_folder/usr/share/pixmaps/myprogram.png

# Hicolor 图标
mkdir ./staging_folder/usr/share/icons
mkdir ./staging_folder/usr/share/icons/hicolor
mkdir ./staging_folder/usr/share/icons/hicolor/scalable
mkdir ./staging_folder/usr/share/icons/hicolor/scalable/apps
cp ./misc/myprogram_logo.svg ./staging_folder/usr/share/icons/hicolor/scalable/apps/myprogram.svg

# 生成 .deb 文件
dpkg-deb --root-owner-group --build ./staging_folder/ ./myprogram_3.1.0_amd64.deb
```

## 安装

```sh
sudo apt install ./myprogram_3.1.0_amd64.deb
```

## 卸载 / 移除

```sh
sudo apt remove myprogram
```
