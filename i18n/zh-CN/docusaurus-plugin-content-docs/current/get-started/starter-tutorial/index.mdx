## .axaml

注意到你项目目录中那些以 `.axaml` 结尾的文件了吗？它是 Avalonia XAML 的缩写，是 Avalonia 特有的文件扩展名，用来区别于普通 XAML 文件。

## 检查 XAML 实时预览器是否可用

如果你刚刚在 Visual Studio 或 JetBrains Rider 中安装了 Avalonia，并且你对 IDE 开发也还比较陌生，那么现在正是检查 XAML 实时预览器是否能正常使用的好时机。

关于如何启用预览器，请参阅 [XAML 实时预览](/docs/app-development/xaml-preview-and-design-settings) 页面。

## 打开主窗口文件

在项目目录的 **Views** 文件夹中，打开 **MainWindow.axaml** 文件。在本教程中，你主要会在这个文件中进行操作。

<Image light={MainWindowFileLocation} alt="展示主窗口文件在文件树中位置的截图。" position="center" maxWidth={400} cornerRadius="true" margin="20,0,50,0"/>

**MainWindow.axaml** 中几乎所有内容都写在 `<Window>...</Window>` 这个 XAML 标签之间。这个标签表示 Avalonia 窗口，也就是你的应用在目标平台上运行的容器。稍后在[自定义 Avalonia 窗口](/docs/get-started/starter-tutorial/customizing-the-avalonia-window)一节中，我们会更详细地讲解它。
